# Command Reference

The complete command reference now lives in the **[Command Library](/commands/)**.

It covers slash commands and context-menu actions, required and optional arguments, descriptions, role access, ticket workflows, moderation, forum review, events, sticky messages, server utilities and developer search.

The four programming search commands have their own expanded guide: [Developer Tools](/commands/developer-tools).

Role access can also depend on Discord permissions, target role hierarchy and the channel where a command is used.
