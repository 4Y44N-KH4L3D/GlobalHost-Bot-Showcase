# GlobalHost

**A shared place for developers to learn, build and help each other.**

GlobalHost is a Discord community for people interested in programming, software development and technology. Whether you're learning your first language, building a project, debugging an issue or sharing something you've made, the aim is to have a place where developers can take part and improve together.

This site explains what the community is about and gives an overview of the tools we use to keep the server organised. The GlobalHost bot is a private project made for this server, not a public bot that other servers can invite.

## What the community is about

### Learn and ask questions

Talk through programming problems, share useful resources and get help when you're stuck. Questions are welcome, whether you're new to coding or already working on projects.

### Build and share projects

Show what you're working on, get feedback, discuss approaches and learn from other people's projects. The goal is to make sharing work useful, not just to post a link and leave.

### Find your people

Meet members interested in languages, backend development, frontend, Linux, cybersecurity, AI, game development and other areas of tech. You can take part in discussions that match your interests.

### Keep the server useful

Moderation, support tickets, forum review, events and server utilities help keep conversations organised and make it easier for members and staff to use the community.

## The tools behind the server

The server uses a custom-built Discord bot for moderation, raid alerts, support tickets, forum review, events and developer search. These tools are built around how GlobalHost operates.

They are documented here for transparency and as a record of the project. **The bot is private to GlobalHost and is not available for other servers to add or use.**
