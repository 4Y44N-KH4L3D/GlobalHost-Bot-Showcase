# Community Tools

**Keep the community organised between moderation incidents.**

The GlobalHost server uses its custom bot for events, sticky messages, announcements and everyday utilities. These features support the community and help staff keep information organised.

## Scheduled events

The **/event** command group lets authorised staff create, list, edit and cancel scheduled events, and view event statistics. Event creation supports a name, start and end time, description and location.

Event management is available to Event Managers, Mods, Admins and the Owner.

## Sticky messages

The **/sticky** command group lets authorised staff create or replace a text sticky, build an embed sticky, or remove a channel's sticky. Sticky messages are restored by the bot after a restart, so key channel guidance does not depend on a moderator manually reposting it.

## Announcements and embeds

- **/announce:** publish a formatted announcement with a title and description.
- **/embed:** use an interactive builder to create a custom embed.
- **/say:** send a message as the bot.

These messaging commands require Admin or Owner access.

## Member and server information

Public utility commands include **/userinfo**, **/avatar**, **/serverinfo**, **/roleinfo**, **/channelinfo** and **/channels**. They show useful details such as account dates, roles, channel settings and IDs without requiring staff to dig through several settings screens.

## Service status

- **/pingbot:** checks whether the bot responds.
- **/status:** checks Discord readiness and the health of its database, GitHub, search and AI services.

## Why keep these together?

Events, sticky messages, announcements and server information are useful on their own. Keeping them alongside moderation, tickets and forum review means fewer separate workflows and one consistent set of access rules.
