## 💬 Built around shared interests

GlobalHost is a developer-focused Discord community for discussing tech, sharing projects, solving problems, and learning from one another.

Bring a project you're working on, ask a question, share something you've discovered, or join a discussion. Whether you're into backend systems, Linux, security, AI, game development, or programming in general, there's room to explore.

## ⚙️ The infrastructure behind the community

A custom Python bot helps keep the GlobalHost server organised. Its private tooling covers:

- 🛡️ **Moderation and AutoMod** — rule enforcement and staff support
- 🚨 **Raid protection** — suspicious join monitoring and staff alerts
- 🎫 **Support tickets** — a route for members to contact staff
- 🧵 **Forum review** — tools for reviewing selected forum activity
- 📢 **Community utilities** — announcements, events, sticky messages, and more
- 💻 **Developer commands** — programming-related search and utilities

> 🔒 The bot is built for GlobalHost and is **not available for other servers to invite**. This repository contains the public showcase and documentation, not the bot's production source code.
